# Seaside Club

A seaside cafe game for kids: catch fish, grill, serve the guests, and grow your club across five stages.
Original code, art and music. Progress is saved in the browser; use the Save code in the Shop to move it between devices.

## Play

https://sameeragarwala-2201.github.io/seaside-club/

On a phone or tablet, open the link and choose "Add to Home Screen" to play it like an app (works offline).
